# Тёплые слова

Адаптивная витрина авторских топперов для букетов с корзиной и оформлением заявки без онлайн-оплаты.

## Что внутри

- 12 карточек товаров и 36 оптимизированных WebP-фотографий;
- адаптация для телефона, планшета и компьютера;
- единый формат фотографий: общий вид, серия и крупный план;
- блоки с доставкой, популярными категориями, отзывами и контактами;
- корзина сохраняется в браузере покупателя;
- форма собирает только имя, телефон и адрес доставки;
- заказ отправляется владельцу в Telegram через защищённый Cloudflare Worker;
- онлайн-оплаты и базы данных нет.

## Как изменить данные

Все тексты, цены, остатки и контакты находятся в `index.html`. Цвета и размеры — в `styles.css`.

В блоке `#contacts` указан номер `8 900 590-68-53`. Публичный логин Telegram не требуется: новые заказы приходят владельцу через закрытого бота.

## Подключение заказов к Telegram

GitHub Pages хранит только публичную часть сайта. Токен Telegram-бота нельзя добавлять в `index.html` или `script.js`, поэтому отправку выполняет Worker из папки `worker`.

1. Создайте бота через `@BotFather` в Telegram и сохраните выданный токен.
2. Напишите созданному боту `/start`.
3. Узнайте свой `chat_id` через метод `getUpdates` Telegram Bot API.
4. Авторизуйтесь в Cloudflare: `npx wrangler login`.
5. Из папки `worker` добавьте секреты:

   ```powershell
   npx wrangler secret put TELEGRAM_BOT_TOKEN
   npx wrangler secret put TELEGRAM_CHAT_ID
   ```

6. Опубликуйте обработчик командой `npx wrangler deploy`.
7. Скопируйте выданный адрес Worker и вставьте его в `index.html`:

   ```html
   <meta name="order-endpoint" content="https://prime-topper-orders.ВАШ_АККАУНТ.workers.dev" />
   ```

Токен бота хранится только в секретах Cloudflare и не попадает в GitHub.

Локальная проверка обработчика без отправки сообщений: `cd worker; npm test`.

## Локальный просмотр

Откройте `index.html` в браузере. Дополнительная сборка не требуется.
